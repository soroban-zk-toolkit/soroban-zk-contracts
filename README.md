## soroban-zk-contracts

> **Implementation status:** development scaffold. The verifier entry points and
> Merkle/nullifier flows are being developed and are not production-ready or
> independently audited. Do not deploy this repository with real funds or use
> its verification results as a security guarantee.

Rust/Soroban smart contracts for zero-knowledge proof verification.

This repository is part of the soroban-zk-toolkit organization and contains on-chain verifier contracts, a nullifier registry, and a Merkle membership verifier.

See the parent org README for contribution and Wave rules.
